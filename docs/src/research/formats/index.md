# Formats

What each chart format can express, and where they structurally disagree.

- [`.sm`](sm.md) — StepMania MSD tag format
- [`.ssc`](ssc.md) — MSD5 successor, the most timing-expressive of the set
- [`.osu`](osu.md) — osu! sectioned format, millisecond-based
- [`.qua`](qua.md) — Quaver YAML, scroll-velocity rich
- [`.chart`](chart.md) — Clone Hero / Guitar Hero tick format
- [`.mid`](mid.md) — MIDI, as used by guitar-family editors
- [`.mc`](mc.md) — Malody JSON
- [`.tmpr`](tmpr.md) — Tempora sync project file
- [`.ttr2_track`](ttr2_track.md) — Tap Tap Revenge's keyed archive of notes timed in seconds
- [Interoperability](interoperability.md) — where conversion is structurally lossy
