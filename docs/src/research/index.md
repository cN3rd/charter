# Research

Distilled prior research on rhythm-game chart editors, chart formats, and the Rust stack for
building one. Each file is a single idea.

Observations are separated from conclusions throughout. Where earlier research reached a verdict,
that verdict is recorded under **Open decision** as one option among others, alongside the
evidence it rests on. Nothing in this section is settled.

Evidence grades used across these files:

| Grade | Meaning |
|---|---|
| measured | A number exists |
| observed | A cited tool demonstrably behaves this way |
| inferred | Reasoned from an observation |
| asserted | No supporting evidence was found |

- [Editors](editors/index.md) — what existing tools do
- [Formats](formats/index.md) — what the file formats can express
- [Topics](topics/index.md) — design questions, each with its open decision
- [Constraints](constraints/index.md) — limits that hold regardless of choices
