# Editors

Source-backed behaviour of existing tools. Verdicts about what to copy live in
[topics](../topics/index.md).

- [ArrowVortex](arrowvortex.md): Windows StepMania/ITG editor, the densest feature reference
- [StepMania editor](stepmania.md): in-game editor, origin of the 48 rows/beat model
- [osu!](osu.md): stable and lazer beatmap editors
- [Quaver](quaver.md): in-game VSRG editor with first-class live mapping
- [Moonscraper](moonscraper.md): Clone Hero `.chart` editor
- [Editor on Fire](editor-on-fire.md): guitar/vocal editor with the widest note domain
- [Etterna](etterna.md): StepMania fork, keyboard community
- [OpenChart](openchart.md): web editor with explicit multi-game goals
- [Tempora](tempora.md): sync-only tool, not an editor
