# Etterna

Windows, macOS and Linux fork of StepMania 5.0.12, focused on keyboard players. MIT by repository
metadata.

Contains loaders for SM, SSC, OSU, BMS, DWI, KSF, SMA and ETT.

The surveyed sources do not establish a distinct modern standalone editor UX. Its relevance is as a
format-compatibility surface and a user community, not as an interaction reference.

See [target audience](../topics/target-audience.md).
